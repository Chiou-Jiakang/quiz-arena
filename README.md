# Quiz Arena

以多元知識問答為主題的全端網頁競技遊戲（開發規劃階段）。

## 遊戲玩法（規劃中）

- 單人暱稱遊玩，不需註冊。
- 每局 10 題、每題 20 秒、四選一。
- 答對 100 分，答錯或逾時 0 分。
- 多元知識類別、難度選擇、成績紀錄與排行榜。
- 深色科技競技場介面。

## 技術規劃

- Frontend：HTML / CSS / JavaScript
- Backend：Node.js / Express
- Database：SQLite
- Tools：VS Code / Git / GitHub
