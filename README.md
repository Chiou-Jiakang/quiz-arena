# Quiz Arena

**Quiz Arena｜知識競技場**

一款以多元知識問答為主題的全端網頁競技遊戲，採用漸進式開發（Iterative Development），從前端互動原型逐步擴充為包含 REST API、資料庫、玩家成績與排行榜的完整系統。

本專案採用 **AI-Assisted Development**，透過 AI 輔助程式碼生成，並搭配人工測試、除錯、Code Review、Git 版本控制及完整開發紀錄，實踐全端網頁開發流程。

**目前版本：v0.1.0 — Homepage & Game Setup**

**開發狀態：前端原型已完成，持續開發中（In Development）**

---

## 1. 專案目標

本專案希望建立一款具備完整遊戲流程、良好使用者體驗與資料持久化能力的線上知識競技平台。

主要開發目標：

- 建立美觀且支援響應式設計的遊戲介面。
- 使用 JavaScript 實作題目切換、倒數計時與計分系統。
- 使用 Node.js 與 Express 建立 RESTful API。
- 使用 SQLite 儲存題庫、玩家資訊與遊戲成績。
- 實作基本資料庫 CRUD 操作。
- 建立個人成績紀錄與排行榜。
- 透過 GitHub 持續追蹤程式碼、功能變更及開發進度。

## 2. 遊戲玩法（MVP 目標）

Quiz Arena 採用單人知識挑戰模式，玩家不需註冊帳號，只需輸入暱稱即可進行遊戲。

預計遊戲規則如下：

| 項目     | 規則                             |
| -------- | -------------------------------- |
| 遊戲模式 | 單人知識問答                     |
| 玩家身分 | 暱稱遊玩，無須註冊               |
| 每局題數 | 10 題                            |
| 題目形式 | 四選一選擇題                     |
| 答題時間 | 每題 20 秒                       |
| 正確答案 | 100 分                           |
| 錯誤答案 | 0 分                             |
| 逾時未答 | 0 分                             |
| 最高總分 | 1,000 分                         |
| 題目類別 | 綜合知識、科技、科學、歷史、地理 |
| 題目難度 | 簡單、中等、困難                 |

MVP 預計提供遊戲結算、答題解析、歷史成績與排行榜。

以上為完整 MVP 的目標規格，部分功能尚未實作。

## 6. 本機執行方式

### 環境需求

- Windows、macOS 或 Linux
- 現代網頁瀏覽器
- Python 3（若使用以下本機伺服器啟動方式）

### 啟動步驟

1. 使用 VS Code 開啟 `quiz-arena` 專案。
2. 在專案根目錄開啟終端機。
3. 執行：

```powershell
python -m http.server 5500 --directory public
```

4. 使用瀏覽器開啟：

`http://localhost:5500`

5. 確認首頁顯示正常後，即可操作遊戲設定介面。

按下 `Ctrl + C` 可以停止伺服器。

目前 v0.1.0 為純前端版本，無須安裝 npm 套件，也不需要啟動 Node.js 後端。

## 9. 開發與版本管理方式

本專案採用 AI 輔助、人工驗證與持續迭代的開發流程。

每次開發包含：

1. 定義本次功能需求。
2. 使用 AI 輔助生成或修改程式碼。
3. 在 VS Code 進行本機測試。
4. 檢查功能、排版及程式邏輯。
5. 修正問題並執行 Code Review。
6. 更新 README、DEVLOG 或 CHANGELOG。
7. 透過 Git Commit 與 Push 保存開發成果。

Commit Message 依照變更性質使用 `feat`、`fix`、`docs`、`refactor`、`test` 等類型，確保每次提交都有明確目的。
