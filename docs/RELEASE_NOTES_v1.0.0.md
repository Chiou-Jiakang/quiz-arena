# Quiz Arena v1.0.0｜正式發行說明

> 適用對象：本機單人全端 MVP。正式 Tag 需在測試完成後建立。

## 核心功能

- 原生 HTML / CSS / JavaScript 網頁、深色響應式介面。
- 十題四選一，科技／科學／歷史／地理／綜合選擇，簡單／中等／困難三種難度。
- Express API 負責抽題、答題驗證、分數與每題 20 秒截止時間。
- SQLite 儲存遊戲與完成成績、排行榜前十名、最近 20 筆歷史成績及逐題回顧。
- HTTP 不公開含答案的 `public/data/questions.json`。
- 提供資料庫完整性檢查與 WAL 安全備份。

## RC 階段已確認的驗收證據

- 自動化測試：65 通過、0 失敗。
- 原始與備份資料庫各顯示 Schema 1、3 筆遊戲、3 筆結果、`valid: true`。
- 本機啟動與基本遊戲操作已確認。

## 本次正式版變更

- 版本號統一 `1.0.0`，HTTP `/api/health` 應回傳 `v1.0.0`。
- 維持既有 SQLite Schema、遊戲規則與歷史資料格式。
- 更新版號斷言與中文文件，保留舊里程碑全部開發紀錄。

## 定稿驗收指令

```powershell
npm test
npm run db:check
npm start
```

在瀏覽器開啟 `http://127.0.0.1:3000/`，確認問答、排行與歷史成績；開啟 `http://127.0.0.1:3000/api/health`，確認 `version` 為 `v1.0.0`。

## 版本限制

本版未包含使用者認證、正式授權、速率限制、防刷榜或公開網路部署資安驗收。未進行全設備、跨瀏覽器、壓力測試或異機還原演練。不可將「本機 MVP 完成」宣稱為「公開營運安全可靠」。
