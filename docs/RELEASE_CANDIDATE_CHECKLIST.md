# Quiz Arena v1.0.0-rc.1｜發布候選版驗收清單

> 此版為 **Release Candidate（候選版）**，不是已完成正式發布；延續 README、CHANGELOG、DEVLOG 的累積歷史，勿以此文件取代既有內容。

## 系統需求與啟動

- Node.js >=22.13.0（建議使用 Node 24 LTS）；Windows PowerShell。
- 在專案根目錄使用 `npm ci`（先前已安裝則可不重新安裝）。
- 使用 `npm test` 執行全部 Node.js 測試。
- 執行 `npm start`，用 `http://127.0.0.1:3000/` 開啟遊戲。
- `/api/health` 應顯示 `v1.0.0-rc.1` 和 `persistence: sqlite`。

## 手動驗收（需逐項填入結果，不得在未驗證前宣稱通過）

- [ ] 首頁、遊戲規則、暱稱與類別／難度設定正常。
- [ ] 每局十題、四選一，且題目不重複；答對 +100、答錯 0。
- [ ] 每題 20 秒限制，最後五秒警示；逾時不加分，無法補答。
- [ ] 題目答完後顯示正確答案與解析；同題連按不重複加分。
- [ ] 第十題後正確結算、逐題回顧、重新挑戰。
- [ ] 中途重新整理可依後端狀態恢復，已逾時則呈現逾時結果。
- [ ] 斷線／伺服器停止時顯示錯誤，恢復後可重新同步。
- [ ] 完成的歷史成績能在伺服器重啟後查詢。
- [ ] 前十名排行榜按分數、正確率、時間排序，最近成績單獨排序。
- [ ] 用 `npm run db:check` 驗證資料庫。
- [ ] 用 `npm run db:backup` 備份，並用 `npm run db:check -- <備份路徑>` 驗證備份。
- [ ] 用 Network 檢查 `/data/questions.json` 無法公開讀取（HTTP 404）。
- [ ] 桌面／手機窄寬、鍵盤操作與主要文字對比人工驗收。

## 資料保護與已知限制

- **不要 `git add data/` 或 `git add backups/`**；SQLite 是本機執行資料。`.gitignore` 應忽略此二目錄。
- SQLite 預設是 WAL 模式，備份不可直接只複製 `.sqlite` 主檔。提供的 `db:backup` 使用 SQLite Online Backup API，並驗證 `integrity_check`。
- 備份預設在 `backups/`；不要覆蓋既有備份，定期將備份另存於不同儲存裝置。
- 本專案仍為本機 MVP：沒有身分驗證、公開網路存取控制、濫用防護、完整題目事實審核與正式滲透測試。
- 目前的權限邊界僅適合本機練習；不應在無額外資安設計下直接部署到網際網路。
- 經 GitHub 完成功能 Commit、文件歷史更新、所有驗收成功後，才考慮 `v1.0.0` 正式標籤。
