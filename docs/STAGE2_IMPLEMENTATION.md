# Quiz Arena v0.2.0 Stage 2 — 單機問答系統

## 本次範圍

- 沿用 v0.1.0 首頁、遊戲設定介面、深色主題。
- 玩家確認設定後以 `fetch()` 讀入既有 `public/data/questions.json`，沿用 `quiz-data.mjs` 之驗證與抽題函式。
- 每局 10 題、不重複、符合所選類別和難度。
- 每題四個按鈕，答對 100 分、答錯 0 分、鎖定已提交答案、顯示正解與解析。
- 顯示得分與題次，最後顯示結算、逐題回顧與相同設定重玩。
- `quiz-engine.mjs` 以純函式管理遊戲進度，可獨立單元測試。

## 本版本的限制

- 20 秒倒數與逾時規則預計在 v0.3.0 加入；目前不計時。
- 成績與遊戲進度僅保留在網頁記憶體，重新整理或離開不儲存。
- 正確答案存在前端 JSON 中，**不具防作弊能力**；正式版將改由 Express 驗證。
- 尚未加入資料庫、排行榜或註冊登入。

## 更新檔案

- 修改 `public/index.html`：增加遊戲與結果區塊，改用 ES modules。
- 修改 `public/css/style.css`：新增問答／回饋／結算的響應式樣式。
- 修改 `public/js/app.js`：整合畫面操作、題庫載入與流程。
- 新增 `public/js/quiz-engine.mjs`：遊戲狀態與計分純函式。
- 新增 `tests/quiz-engine.test.mjs`：進度、計分、防重複提交、結算等測試。

## 自動化測試

```powershell
node --test tests/*.test.mjs
```

開發環境已執行兩組測試共 14 項，通過 14 項；仍需要在 Windows 瀏覽器自行執行互動與 RWD 驗收。

## 手動驗收

1. 首頁、返回首頁及遊戲規則仍正常。
2. 設定暱稱、類別、難度，按「開始答題」進入題目頁。
3. 題目共有四個可點選答案；點擊後正確/錯誤與解析正確顯示。
4. 同一題無法再次點擊計分，必須按下一題才能前進。
5. 十題結束後得分介於 0–1000，答對題數 ×100 等於總分。
6. 逐題回顧與答題紀錄一致，且可以相同設定重玩。
7. 缺少題庫時顯示可理解錯誤；瀏覽器主控台沒有非預期例外。
8. 手機窄畫面可以正常點擊選項，不會橫向溢出。
