# Quiz Arena v0.3.0 — 每題 20 秒倒數與逾時處理

## 功能範圍

- 每題正式呈現時開始獨立 20 秒倒數；剩餘時間與進度條即時更新。
- 使用 `performance.now()` 的單調時間作為截止基準，不以 `setInterval` 執行次數累積秒數；瀏覽器背景延後排程不會延長答題期限。
- 逾時後自動提交「未作答」紀錄（`chosenIndex: null`, `timedOut: true`），分數保持不變，顯示正解及解析。
- 玩家按答案時再次同步檢查截止時間，避免排程延遲導致截止後答題仍被計為正確。
- 作答、逾時、返回首頁、結果頁及重新挑戰時停止既有計時器；換題時使用新的 20 秒期限。回饋期間不倒數。
- 修正題庫正在載入期間退出遊戲、舊異步結果晚到的畫面覆蓋風險。
- 十題結算回顧分別標示答對、答錯、逾時，並正確顯示「未作答（時間到）」。

## 重要設計邊界

- `public/js/quiz-timer.mjs`：可注入時鐘與排程函式的獨立計時器，便於無需等待真實 20 秒的單元測試。
- `public/js/quiz-engine.mjs`：新增 `submitTimeout`，保留原有 `submitAnswer` API，避免改壞 v0.2.0 測試。
- `public/js/app.js`：整合 DOM 與計時器生命週期；停止舊計時器後再建立新的一個。
- 本版本仍為**前端單機展示**。使用者修改瀏覽器程式或系統環境可能繞過驗證；正式防作弊需要 Express 伺服器的獨立截止時間與答案驗證。
- 若機器進入休眠或瀏覽器凍結，恢復後會在下一次 JavaScript 執行／互動時補判是否逾時；並非在停機期間仍能即時更新畫面。

## 自動化測試

在專案根目錄執行：

```powershell
node --test tests/*.test.mjs
```

預期測試涵蓋：既有 14 項 + 計時器 6 項 + 逾時遊戲狀態 4 項，共 **24 項**。

## 瀏覽器驗收

1. 新遊戲第 1 題從 `20 秒` 開始倒數，進度條隨時間縮短。
2. 倒數到最後五秒進入醒目狀態；未作答至期限即出現「時間到！」，該題 0 分。
3. 逾時後所有選項鎖定、顯示正解；下一題重新從 20 秒開始。
4. 在 20 秒內答對 +100、答錯 +0；作答後計時停止，回饋不會被逾時覆蓋。
5. 快速連點同一選項、逾時與點選同時發生，不會重複紀錄或加分。
6. 離開後重新開始、完成後再玩一次，皆從新的一題 20 秒開始，無多個計時器共存。
7. 切換瀏覽器分頁超過 20 秒後返回，當前題目應判為逾時；實際截止時間不應因隱藏頁面而延長。
8. 十題後檢查逐題回顧顯示答對、答錯與逾時；分數及答對率一致。
9. 手機窄版時倒數區與四個選項可讀可點，無意外水平捲動。

## 安裝方式

本補丁包含 `install_v0.3.py`：對 GitHub 第七筆 Commit `9288af8` 對應的 v0.2.0 工作樹進行**唯一片段比對**後再修改。執行前請先確認 `git status` 沒有未儲存的程式變更；其過程會自動備份到專案同層的 `quiz-arena-v0.3.0-before-upgrade`。

安裝成功後，進行自動化與瀏覽器驗收，再自行 Commit / Push；不要在未通過測試前提交。
