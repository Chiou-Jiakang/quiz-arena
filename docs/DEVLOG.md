# Quiz Arena 開發日誌

## 2026-10-17｜Session 02：Quiz Arena v0.1.0 前端開發

### 一、本次開發目標

完成 Quiz Arena 第一版前端互動原型，包含深色科技競技場風格首頁、基本遊戲資訊與玩家設定介面，作為後續實作問答遊戲的基礎。

### 二、實作內容

**1. 首頁 UI 建立**

- 建立 `public/index.html`，定義網頁基本結構。
- 建立 `public/css/style.css`，設計深色科技風格介面。
- 建立 `public/js/app.js`，處理前端基本互動。
- 加入 Quiz Arena 品牌標題、遊戲介紹與特色區塊。
- 加入遊戲規則說明及開始挑戰按鈕。
- 實作基本響應式排版。

**2. 遊戲設定介面**

- 建立玩家暱稱輸入欄位。
- 提供綜合知識、科技、科學、歷史、地理等類別選項。
- 提供簡單、中等、困難三種難度選項。
- 顯示每局 10 題、每題 20 秒、答對 100 分的遊戲規則。
- 加入設定確認與返回首頁功能。

**3. JavaScript 基本互動**

- 使用 DOM 操作切換首頁及設定介面。
- 使用事件監聽器處理按鈕點擊。
- 使用表單提交事件讀取玩家設定。
- 設定完成後顯示玩家暱稱、選擇類別與難度。

### 四、發現的問題與改善方向

**問題 1：確認遊戲設定後缺少明顯回饋**

目前按下「確認遊戲設定」後，系統僅在按鈕下方顯示設定完成訊息。由於訊息較不醒目，使用者可能誤以為按鈕沒有反應。

原因：v0.1.0 尚未實作正式答題畫面，設定介面僅提供前端原型測試。

改善方向：在 v0.2.0 加入正式答題畫面，完成設定後直接開始遊戲。

**問題 2：網站 favicon 尚未建立**

本機伺服器曾回傳 `/favicon.ico` HTTP 404，表示瀏覽器找不到網站圖示。

影響：不影響目前遊戲首頁及基本互動功能。

改善方向：後續加入 Quiz Arena 專屬 favicon。
